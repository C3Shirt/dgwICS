# dgwICS source snapshot

This repository contains the Factory I/O and CODESYS agent implementation, the local
manual-step dashboard, adapters, prompts, component knowledge, tests and documentation.

Local service configuration, API keys, PLC credentials, environment files, generated
runs/training data, Factory I/O scenes and binary PLC projects are excluded.
`config.example.json` contains configuration structure and environment variable names,
without credential values. Supply your own configuration and installed simulation software.

This is a source snapshot captured during ongoing development. Offline tests are
reported separately and do not certify current live industrial simulation acceptance.
